📌 Descrição
Este repositório contém um guia completo e prático sobre manipulação de arquivos em Python. O conteúdo foi estruturado com base em uma apresentação educacional e inclui exemplos comentados para cada tópico abordado. Ideal para iniciantes, estudantes e profissionais que desejam dominar operações com arquivos .txt e .csv.

🎯 Objetivos
- Compreender a importância da manipulação de arquivos
- Aprender a abrir, ler, escrever e fechar arquivos
- Gerenciar arquivos e diretórios com os módulos os e shutil
- Tratar exceções comuns durante operações de E/S
- Aplicar boas práticas no uso de arquivos
- Trabalhar com arquivos CSV usando o módulo csv

📚 Conteúdo
O script principal está dividido nos seguintes tópicos:
- 🔓 Abrindo e Fechando Arquivos
- 📖 Lendo de um Arquivo
- ✍️ Escrevendo em um Arquivo
- 🗂️ Gerenciando Arquivos e Diretórios
- ⚠️ Tratamento de Exceções
- ✅ Boas Práticas
- 📊 Trabalhando com Arquivos CSV
Cada seção contém 4 exemplos práticos com comentários explicativos.

🛠️ Pré-requisitos
- Python 3.7 ou superior
- Editor de código (VSCode recomendado)
